# 糯糯 v3 设计说明：更解压的闯关、更多场景、正面镜头

> 本文说明 v3 版本"为什么这样设计"，以及每条设计参考了哪些成熟作品的做法。实现细节见源码注释。

## 1. 调研结论（成熟做法 → 我们怎么用）

| 成熟作品 / 做法 | 公开资料里的关键点 | 在糯糯里的落地 |
|---|---|---|
| **Fall Guys**（Mediatonic） | 灵感来自《风云挑战》《Wipeout》等障碍秀；弹跳垫、跷跷板、可以撞开的软门；"80% 技巧 + 20% 混乱"；角色要"看起来软软的、弹弹的"，每关能用三个词说清楚 | 新增 **蹦床 / 跳跳石 / 滑滑梯 / 摇摇桥 / 气球飘飘** 五种闯关元素；全部软软弹弹（落地挤压回弹、平台下沉再弹起）；直播挂机不需要"失败"，保留蓄力 → 起跳 → 落地的爽感 |
| **3D 马里奥**（林田宏一的"起承转合"） | 每关围绕一个机制：引入 → 发展 → 转折 → 收尾 | 每个世界按"起（招牌解压站）→ 承（跳跳石）→ 转（滑梯 / 蹦床，画面最热闹）→ 合（巨型终点）"编排，站点之间穿插小挑战 |
| **Crash Bandicoot** 追逐关 | 镜头放在角色正前方，角色迎着镜头跑，观众一直看到它的脸 | 镜头改为"正面 / 3/4 正面"为主：赛道沿 +x，镜头在糯糯前方后退跟拍；滑梯从底部迎着拍，蹦床低机位仰拍 |
| **PowerWash Simulator**（FuturLab） | 玩家反馈里出现最多的词是"Satisfying"；即时的视觉反馈、没有压力、看得见的清洁进度 | 打扫世界：擦地板时脏脚印一擦就亮、灰尘一扫就聚成一堆进簸箕；每个任务都有进度、没有失败 |
| **Unpacking**（Witch Beam） | 大量细致的拟音，物品"放进去"的声音和视觉吸附相互配合，让放置有"实体感" | 收纳玩具：每个玩具飞进玩具箱的瞬间配一声真实录制的"咚 / 啵"；叠好的衣服落到那一摞上也有放置声 |
| **Cooking Mama** | 一道菜由一串每个不到 10 秒的小任务组成（切、煎、翻面……），难度宽松、画风可爱 | 厨房世界是一条"菜谱任务链"：切蔬菜 → 打蛋搅面糊 → 煎松饼翻面 → 踩奶揉面团 → 裱花蛋糕 |
| **Disney / Pixar 角色设计 & 动画原则** | "婴儿图式"（大头、大眼睛、圆脸颊）；挤压拉伸时保持体积 | 糯糯换上彩色虹膜 + 双高光的大眼睛、会动的小眉毛、小鼻头、脚底粉色肉垫；所有动作都有挤压拉伸和弹簧次级运动 |
| **Toca Boca 等儿童向作品** | 鲜艳柔和的配色、圆润造型、清晰的描边 | 场景改用暖色主光 + 冷色补光 + 逆光轮廓光，PBR Neutral 色调映射保留糖果色；远山、云朵、起点气球拱门增加纵深 |

## 2. 关卡结构

```
起点 ─ 解压站① ─ 闯关元素① ─ 解压站② ─ 闯关元素②（转折：滑梯/蹦床）─ 解压站③ ─ 闯关元素③ ─ 解压站④ ─ 巨型终点
```

- 8 个世界：雪国棉花糖谷、秋日落叶林、史莱姆果冻工坊、雨天水洼花园、彩虹沙滩、软糖键盘小屋、**糯糯小厨房（新）**、**糯糯大扫除（新）**。
- 每个世界有 5 个站点和 4 种闯关元素可选，每次随机组合（首站固定为招牌材质；厨房和打扫按菜谱 / 打扫流程固定顺序）。
- 一关约 3 分钟，左上角进度点：圆点 = 解压站 / 任务站，小菱形 = 闯关小挑战，★ = 终点。

## 3. 镜头设计（让观众看到可爱的正脸）

- 赛道方向固定为 +x，**默认镜头在糯糯前方偏侧**（3/4 正面），随它前进不断后退跟拍；身后留下的脚印也在画面里。
- 解压站上糯糯走一条迎着镜头的 S 形路线（不再来回横穿），踩奶、坐下、俯身按时**转身面向镜头**，用正脸特写。
- 任务站像美食节目：镜头在操作台正前方，糯糯在台子后面面对观众干活。
- 跳舞答谢、挥手、谢谢关注：糯糯转向镜头，镜头在它正前方。
- 切换机位时用"绕目标的弧线"插值，不会穿过糯糯；滑梯这种大转场用硬切，像剪辑过的解压视频。
- **"对着镜头演"（cheat to camera）**：影视表演的常用技巧，身体稍微朝镜头偏一点，观众就能看清表情。糯糯走路时身体最多朝镜头偏 20°；S 形路线每一段最多偏离前进方向约 25°；跟拍机位也会随前进方向转一点。实测走 S 形时镜头相对糯糯朝向的角度在 3/4 正面范围内（约 10°~45°），不再出现侧面。
- **完整入画**：以糯糯为主体的机位按相机视角自动算"最近距离"（横屏垂直视角 40°；竖屏 52° 但水平视角很窄），糯糯最多占画面高度的 62%、宽度的 78%，从耳朵尖到小脚都在画面里，竖屏也不会被裁掉半张脸。
- **反打镜头**：回头看脚印时镜头硬切到脚印的另一头往回拍：一串脚印在前景，回头的糯糯正对观众（以前是从前面拍，会拍到后背）。
- 气球 / 雨伞飘过河时，糯糯身体转向镜头一侧"侧着飘"，镜头看向飘在空中的糯糯本身，小伞和气球也完整入画。

## 4. 声音与声画同步

- 删除了舞曲 **Fluffing a Duck**：频谱分析发现它在约 29.7 秒处有一段 3.5 kHz 的窄带尖音，只比整体响度低 5 dB（其它舞曲都低 9 dB 以上），听感明显刺耳。
- 同时删除了环境声里的鸟鸣、虫鸣（2~6 kHz 的尖叫声），落叶林改用"林间微风"；糖纸声换成更柔和的塑料糖纸录音；史莱姆拉丝、踩史莱姆整体柔化。
- 打包工具给每个录音做"体检"并写进 `manifest.json`：起音位置 `onset`、感知锐度 `sharp`、2~5 kHz 尖音 `pierce`；自检会拒绝任何刺耳的素材。
- 播放时从起音前 6 毫秒开始放，"咔嚓""啪"正好落在画面里脚着地 / 刀落到砧板的那一帧；所有道具动作的声音都由动画的"接触帧"回调触发。
- 音频输出改为低延迟模式（`interactive`）；舞蹈的拍子直接读音乐播放时钟（并扣除输出延迟），长时间也不会错拍。
- 母线上加了轻微的"去刺耳"均衡：踩踏声 8.5 kHz 以上 -2.5 dB、舞曲 3.2 kHz -2 dB、环境声 7 kHz 以上 -3 dB。

## 5. v3.1 打磨：穿模、画风统一、动作细节

### 5.1 穿模：先量出来，再一个个修

- **逐帧审计工具**：页面加 `?manual` 后游戏不自己走，由 `window.__advance(秒)` 按游戏时间一小步一小步推进（每一步之间让出微任务，`await` 链照常衔接）。每 0.1 秒检查三件事：① 场景里的网格顶点有没有进入糯糯的身体（身体形状按建模时"底部压扁、下半身微鼓"的变形精确逆推）；② 从身体中心向 60 个方向发射线，检查大平面有没有穿过身体；③ 手里的道具有没有扎进自己身体。8 个世界全部跑过，发现的问题和修法：

| 问题 | 原因 | 修法 |
|---|---|---|
| 爬滑梯楼梯时肚子"吃进"台阶 | 糯糯的肚子底部是圆的，台阶坡度超过 16° 左右就一定会顶进下一级 | 楼梯换成**果冻弹弹垫**：跳上去弹两下蓄力，"duang"地一下先往上、再往前弹上平台（抛物线离线算过，肚子离平台前缘留着空隙） |
| 滑下来时身体穿过滑道壁 | 人为加的"过弯倾斜"把身体压进槽壁；陡的地方槽的横截面是斜的，竖直往下放会陷进槽底 | 糯糯沿着槽底的**横截面法线**坐正，取消人为倾斜，滑道半径 0.66 → 0.72；离线几何检查整段滑行和槽面零相交 |
| 站在平台上挥手时碰到滑道口 | 平台太短 | 平台加长到 1.1 |
| 滑出滑道时擦着盆沿、冲进雪堆的边 | 滑道末端太低，伸到落地盆里面 | 滑道末端停在盆边、比盆沿高；落地前一瞬间先把球 / 雪堆冲开 |
| 坐在面团 / 太空沙里时身体被一块平板切到 | 材料下面是一块实心盒子，表面一凹下去盒子顶就露出来 | 侧面改成四面薄墙，里面是空的 |
| 在史莱姆里坐得很深时碰到小路 | 嵌在小路里的站点下面还铺着整块小路 | 站点托盘正下方不铺小路，只在两边留窄窄的路边（缝线小圆点照样连着） |
| 扫地、拖地挪步时扫帚 / 拖把穿过身体 | 走路时道具停在原地，身体走进道具里 | `walkCarry`：道具和两只手的目标跟着身体一起平移 |
| 收玩具时玩具在肚子里 | 玩具在小路正中间；蹲下时肚子变宽 | 玩具摆在小路靠镜头的一边，糯糯站在斜后方，玩具正好在右手前方 0.6 |
| 沙子、雪、史莱姆"长进"肚子 | 脚印边缘的隆起、黏稠材质慢慢回流 | 材料顺着圆肚子**凹下去**（只改画面上的高度，不影响脚下的物理高度，否则会越陷越深） |
| 史莱姆拉丝从肚子底下戳进身体 | 拉丝是竖直往上长的 | 丝从史莱姆表面连到小手 / 肚子边缘，碰到身体就停在身体表面 |
| 在托盘边上坐下，压到边框 | 坐下前没有挪位置 | 坐下前先挪到离边框足够远的地方 |
| 落进球池 / 枕头堆时被球穿过 | 被砸飞的球又落回原位（身体里） | 砸出一个坑：肚子底下的球挤到四周堆成一圈 |
| 雪堆、面粉堆从身体里冒出来 | 雪堆被砸扁后又弹回原来的高度 | 雪堆一直扁着，糯糯坐在上面 |
| 闯关元素落地后顶到果冻 / 面包块 | 落地点离下一段起点只有 0.43 | 下一段是一块块要跳上去的东西时多留 0.4 |
| 靠在路边的拖把被蹭到 | 放在离路中间 0.35 的地方 | 挪一小步，靠在路外侧 0.68；放好后退回小路中间再走 |
| 站在滑梯起跳点时后背碰到上一段的果冻块 | 起跳点比别的闯关元素更靠后 | 排路线时按起跳点的位置自动多留空 |
| 在巨型捏捏上蹦跳时落进捏捏里 | 跳在空中这段时间里捏捏慢慢鼓回来了，落点还是起跳时算的高度 | 落点跟着真实的表面走（`liveY`） |

- 自检里加了三条"穿模保护"（滑梯没有楼梯、软材料会凹下去、拿着道具走路用 `walkCarry`），以后改代码不会退回去。

### 5.2 动作细节（预备 → 接触 → 跟随）

- **煎松饼**：锅柄做长、朝着糯糯的左手；左手握着锅柄，右手倒面糊、翻面；冒泡时轻轻晃锅，翻面那一下左手把锅往上一颠；端松饼去盘子前先松开锅柄。
- **史莱姆**：俯身用小手戳三下，丝从小坑一直连到小手，越拉越长、越来越细，然后"啪"地断开；坐下起身时，肚子边上拉出一圈丝。
- **太空沙 / 面团**：两只小手按出手印，用手指划出一道沟——小手按在哪里，印子就在哪里。
- **收玩具**：走到玩具斜后方、蹲下捡起、举一举，预备动作往身体外侧收手，再往前一甩扔进箱子。
- **叠衣服**：从篮子里抓起一团衣服，拎着领口提起来抖两下，再像铺毛巾一样往前一甩铺平（以前是凭空"弹"开）；左右两边、领口一半依次翻过去，拍两下压平，摞到右边。
- **滑滑梯**：弹弹垫被压扁、回弹、冒小星星；空中侧着身子对着镜头，落地后在顶上挥手（镜头在平台左前方，滑道口不会挡住她）。

### 5.3 画风统一（动画电影的常用做法）

- **后期柔光 + 调色**：亮的地方（雪、亮片、果冻高光、窗户）轻轻晕开，亮部偏暖、暗部偏冷，饱和度略高；帧率不够时自动关闭（`config.json` 的 `post` 也可以关）。
- **布光**：暖色主光 + 偏蓝的天光补光 + 地面反光，阴影偏冷紫，整体更通透。
- **室内（厨房、卧室）**：窗外是手绘的蓝天白云、远处小山坡；几束柔光从窗户斜照进来；墙根、墙和台面相接处有柔和的接触阴影；厨房瓷砖每块都有上亮下暗的渐变、顶边高光和凹下去的砖缝。
- **逐个世界校色**：雪国降低柔光（白雪不发灰）、饱和度略高；落叶林的树换成橙、金、枫红的秋叶；雨天花园的草地更清新、雾更淡；沙滩换成弯弯的椰子树、沙堡、条纹沙滩伞和沙滩球（以前多是海底的珊瑚）。
- **户外**：每个世界远处有一座"故事书里的房子"——雪国的雪屋、落叶林的林间小屋、雨天花园会转的风车、沙滩的灯塔、史莱姆工坊的糖果城堡、玩具世界的积木城堡，窗户都暖暖地亮着（冷色场景里的暖色焦点，动画电影常用的冷暖对比）；地面按世界撒满小装饰（草丛、落叶、贝壳、糖珠……），装饰物之间不穿插；所有道具统一的"贴地暗、朝上暖"手绘明暗。
