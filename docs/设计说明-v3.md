# 糯糯 v3 设计说明：更解压的闯关、更多场景、正面镜头

> 本文说明 v3 版本"为什么这样设计"，以及每条设计参考了哪些成熟作品的做法。实现细节见源码注释。

## 1. 调研结论（成熟做法 → 我们怎么用）

| 成熟作品 / 做法 | 公开资料里的关键点 | 在糯糯里的落地 |
|---|---|---|
| **Fall Guys**（Mediatonic） | 灵感来自《风云挑战》《Wipeout》等障碍秀；弹跳垫、跷跷板、可以撞开的软门；"80% 技巧 + 20% 混乱"；角色要"看起来软软的、弹弹的"，每关能用三个词说清楚 | 新增 **蹦床 / 跳跳石 / 滑滑梯 / 摇摇桥 / 气球飘飘** 五种闯关元素；全部软软弹弹（落地挤压回弹、平台下沉再弹起）；直播挂机不需要"失败"，保留蓄力 → 起跳 → 落地的爽感 |
| **3D 马里奥**（林田宏一的"起承转合"） | 每关围绕一个机制：引入 → 发展 → 转折 → 收尾 | 每个世界按"起（招牌解压站）→ 承（跳跳石）→ 转（滑梯 / 蹦床，画面最热闹）→ 合（巨型终点）"编排，站点之间穿插小挑战 |
| **Crash Bandicoot** 追逐关 | 镜头放在角色正前方，角色迎着镜头跑，观众一直看到它的脸 | 镜头改为"正面 / 3/4 正面"为主：赛道沿 +x，镜头在糯糯前方后退跟拍；滑梯从底部迎着拍，蹦床低机位仰拍 |
| **PowerWash Simulator**（FuturLab） | 玩家反馈里出现最多的词是"Satisfying"；即时的视觉反馈、没有压力、看得见的清洁进度 | 打扫世界：擦地板时脏脚印一擦就亮、灰尘一扫就聚成一堆进簸箕；每个任务都有进度、没有失败 |
| **Unpacking**（Witch Beam） | 大量细致的拟音，物品"放进去"的声音和视觉吸附相互配合，让放置有"实体感" | 收纳玩具：每个玩具飞进玩具箱的瞬间配一声真实录制的"咚 / 啵"；叠好的衣服落到那一摞上也有放置声 |
| **Cooking Mama** | 一道菜由一串每个不到 10 秒的小任务组成（切、煎、翻面……），难度宽松、画风可爱 | 厨房世界是一条"菜谱任务链"：切蔬菜 → 打蛋搅面糊 → 煎松饼翻面 → 踩奶揉面团 → 裱花蛋糕 |
| **Disney / Pixar 角色设计 & 动画原则** | "婴儿图式"（大头、大眼睛、圆脸颊）；挤压拉伸时保持体积 | 糯糯换上彩色虹膜 + 双高光的大眼睛、会动的小眉毛、小鼻头、脚底粉色肉垫；所有动作都有挤压拉伸和弹簧次级运动 |
| **Toca Boca 等儿童向作品** | 鲜艳柔和的配色、圆润造型、清晰的描边 | 场景改用暖色主光 + 冷色补光 + 逆光轮廓光，PBR Neutral 色调映射保留糖果色；远山、云朵、起点气球拱门增加纵深 |

## 2. 关卡结构

```
起点 ─ 解压站① ─ 闯关元素① ─ 解压站② ─ 闯关元素②（转折：滑梯/蹦床）─ 解压站③ ─ 闯关元素③ ─ 解压站④ ─ 巨型终点
```

- 8 个世界：雪国棉花糖谷、秋日落叶林、史莱姆果冻工坊、雨天水洼花园、彩虹沙滩、软糖键盘小屋、**糯糯小厨房（新）**、**糯糯大扫除（新）**。
- 每个世界有 5 个站点和 4 种闯关元素可选，每次随机组合（首站固定为招牌材质；厨房和打扫按菜谱 / 打扫流程固定顺序）。
- 一关约 3 分钟，左上角进度点：圆点 = 解压站 / 任务站，小菱形 = 闯关小挑战，★ = 终点。

### 2.1 五种闯关元素

| 元素 | 怎么玩 | 声音（全部真实录音） | 镜头 |
|---|---|---|---|
| 跳跳石 | 雪球 / 蘑菇伞 / 软糖 / 荷叶 / 礁石 / 积木 / 瓶盖 / 抱枕，一颗颗跳过小河；踩上去石头会往下一沉、水面泛起涟漪 | 按主题：踩雪、轻落地、果冻、沙子、放置声 | 侧前方 3/4 |
| 蹦床 | 蘑菇 / 果冻 / 布丁 / 蹦床 / 沙滩球 / 大床；面向镜头连跳三下，一下比一下高，最后一下空翻 | 真实弹力球录音 + 起跳"呼"声 | 低机位正面仰拍 |
| 滑滑梯 | 跳上果冻垫弹两下、"嘣"地弹上平台 → 在顶上对镜头挥手 → 坐着滑下 S 形滑道 → 扑进球池 / 雪堆 / 落叶堆 / 面粉堆 / 枕头堆 / 小水池 | 果冻"duang"、"呼～"、滑道摩擦声、落地声 | 底部迎着拍（正脸） |
| 气球飘飘 | 抓住气球（雨天是小雨伞）飘过小河，小脚晃呀晃，落地后气球自己飞上天 | 呼声、轻落地 | 侧前方跟拍 |
| 摇摇桥 | 小心翼翼地张开小手走过晃动的木板 / 积木 / 果冻桥 | 木头、地毯脚步 | 正面 |

### 2.2 新场景的任务站

**糯糯小厨房**（像美食节目：糯糯站在操作台后面、面朝观众）

| 任务 | 解压点 | 声音 |
|---|---|---|
| 切切蔬菜 | 胡萝卜、黄瓜一片片切下，切面朝上排成一扇 | 木砧板"咚咚"（真实录音） |
| 打蛋搅面糊 | 蛋黄"啵"地落进碗里，面粉和蛋黄被搅成顺滑的奶油色 | 敲蛋、落进碗里、黏黏的搅拌声 |
| 煎松饼 | 倒面糊、表面冒小泡泡、锅铲一挑翻面、叠成一摞再放块黄油 | 面糊、煎锅滋滋（雨声拟音）、翻面"呼"、放置声 |
| 踩奶揉面团 | 糯糯跳上面团踩奶（猫咪踩奶在英文里就叫 making biscuits） | 慢回弹捏捏 |
| 裱花蛋糕 | 一圈奶油花一朵朵"长"出来，最后放草莓、撒糖珠 | 软软的挤压声 |

**糯糯大扫除**（PowerWash / Unpacking 式即时反馈）

| 任务 | 解压点 | 声音 |
|---|---|---|
| 扫扫灰尘 | 毛茸茸的灰尘团被一下下扫成一堆，最后全进簸箕 | 真实的扫帚 / 布料刷声 |
| 擦擦地板 | 泥点和小泥脚印一擦就露出亮晶晶的地砖 | 布料擦拭声 |
| 叠叠衣服 | 小 T 恤左折、右折、对折，整整齐齐落到那一摞上 | 布料沙沙、放置声 |
| 玩具回家 | 散落的积木、小球、星星、小黄鸭一个个飞进玩具箱 | 放置"咚 / 啵" |
| 泡泡浴盆 | 一脚踩破一片彩虹肥皂泡 | 真实泡泡录音 |

## 3. 镜头设计（让观众看到可爱的正脸）

- 赛道方向固定为 +x，**默认镜头在糯糯前方偏侧**（3/4 正面），随它前进不断后退跟拍；身后留下的脚印也在画面里。
- 解压站上糯糯走一条迎着镜头的 S 形路线（不再来回横穿），踩奶、坐下、俯身按时**转身面向镜头**，用正脸特写。
- 任务站像美食节目：镜头在操作台正前方，糯糯在台子后面面对观众干活。
- 跳舞答谢、挥手、谢谢关注：糯糯转向镜头，镜头在它正前方。
- 切换机位时用"绕目标的弧线"插值，不会穿过糯糯；滑梯这种大转场用硬切，像剪辑过的解压视频。
- **"对着镜头演"（cheat to camera）**：影视表演的常用技巧，身体稍微朝镜头偏一点，观众就能看清表情。糯糯走路时身体最多朝镜头偏 20°；S 形路线每一段最多偏离前进方向约 25°；跟拍机位也会随前进方向转一点。实测走 S 形时镜头相对糯糯朝向的角度在 3/4 正面范围内（约 10°~45°），不再出现侧面。
- **完整入画**：以糯糯为主体的机位按相机视角自动算"最近距离"（横屏垂直视角 40°；竖屏 52° 但水平视角很窄），糯糯最多占画面高度的 62%、宽度的 78%，从耳朵尖到小脚都在画面里，竖屏也不会被裁掉半张脸。
- **反打镜头**：回头看脚印时镜头硬切到脚印的另一头往回拍：一串脚印在前景，回头的糯糯正对观众（以前是从前面拍，会拍到后背）。
- 气球 / 雨伞飘过河时，糯糯身体转向镜头一侧"侧着飘"，镜头看向飘在空中的糯糯本身，小伞和气球也完整入画。

## 4. 声音与声画同步

- 删除了舞曲 **Fluffing a Duck**：频谱分析发现它在约 29.7 秒处有一段 3.5 kHz 的窄带尖音，只比整体响度低 5 dB（其它舞曲都低 9 dB 以上），听感明显刺耳。
- 同时删除了环境声里的鸟鸣、虫鸣（2~6 kHz 的尖叫声），落叶林改用"林间微风"；糖纸声换成更柔和的塑料糖纸录音；史莱姆拉丝、踩史莱姆整体柔化。
- 打包工具给每个录音做"体检"并写进 `manifest.json`：起音位置 `onset`、感知锐度 `sharp`、2~5 kHz 尖音 `pierce`；自检会拒绝任何刺耳的素材。
- 播放时从起音前 6 毫秒开始放，"咔嚓""啪"正好落在画面里脚着地 / 刀落到砧板的那一帧；所有道具动作的声音都由动画的"接触帧"回调触发。
- 音频输出改为低延迟模式（`interactive`）；舞蹈的拍子直接读音乐播放时钟（并扣除输出延迟），长时间也不会错拍。
- 母线上加了轻微的"去刺耳"均衡：踩踏声 8.5 kHz 以上 -2.5 dB、舞曲 3.2 kHz -2 dB、环境声 7 kHz 以上 -3 dB。
