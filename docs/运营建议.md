# 运营建议：让成年人进来、留下、互动

> 程序能解决的是"画面和玩法"。"来的是什么人、留不留得住、平台给不给流量"要靠运营。
> 下面的建议来自两部分：① 公开的行业报道和第三方运营文章（文末有来源，**不是平台官方规则**，数字和规则以抖音最新公告为准）；② 这个项目的设计意图（每个功能是为哪个运营动作准备的）。
> 没有人能保证效果，请先小规模试、看数据、再调整。

## 0. 一页纸版本

1. **别纯挂机**：有人在场、开麦带着玩，既合规又涨互动。
2. **换时段**：晚上 9 点以后开播，避开放学后和周末白天。
3. **换说法**：标题、封面、话题、口播都对成年人说话（"下班了，来把今天的烦恼踩扁"）。
4. **换投放**：DOU+ / 直播加热用「自定义定向」，年龄避开最小的档，兴趣选解压 / ASMR / 助眠 / 治愈；或者选"达人相似粉丝"。
5. **盯两个数**：平均停留时长、互动率。礼物先放一边。
6. **用好免费工具**：福袋（口令评论 + 开奖倒计时）、粉丝团。
7. **每 40 秒给一个理由留下**：程序已经安排了投票、开盲盒、砸宝箱，你要做的是把它们喊出来。

## 1. 为什么来的都是小朋友，怎么改

可能的原因（按影响从大到小猜测，需要你用数据验证）：

- **冷启动把你归错了类**。直播间和账号都有"标签"：最初进来并停留、互动的人是什么样，系统就继续找相似的人。可爱的卡通画面 + 不限人群的投放 + 白天 / 傍晚开播，最先停下来的很容易是小朋友，之后就越推越小。
- **文案在对小朋友说话**。标题、封面、口播里如果是"可爱小宠物闯关""小朋友快来"，等于自己选了观众。
- **内容里没有成年人的抓手**。上一版只有"看可爱的东西走路"；成年人需要一个和自己有关的理由。

对应的改法：

### 1.1 时段

- 首选 **晚 9 点 ~ 凌晨 1 点**：下班后、睡前，是解压 / 助眠内容的主场；未成年人这个时段在线少（青少年模式还有夜间时段限制）。
- 次选工作日午休（12:00~13:30）。
- 尽量避开：工作日 16:00~20:00（放学后）、周末和寒暑假的白天。

### 1.2 标题、封面、话题、口播

| | 容易吸引小朋友的写法 | 换成这样 |
|---|---|---|
| 标题 | 超可爱萌宠闯关，小朋友最爱 | 下班了，把今天的烦恼写下来，糯糯帮你踩扁 |
| | 可爱小兔子大冒险 | 打工人解压现场｜弹幕写烦恼，踩扁它 |
| | | 睡前十分钟｜真实录音 ASMR｜踩雪、捏史莱姆 |
| 话题 | #萌宠 #卡通 #儿童 | #解压 #ASMR #助眠 #打工人 #治愈 #盲盒 |
| 口播 | 小朋友们点点赞 | 新进来的朋友，弹幕打出今天最烦的两个字，马上给你踩扁 |

程序里可以改的：

- `config.json` 的 `game.hud.tips`：把轮播提示换成你的直播间口号（默认提示已经是"弹幕写下你的烦恼（比如「加班」）"这种成年人能接的话）。
- `web/js/game/cheer.js` 最下面的 `WORRIES`：内置的烦恼清单（加班、周一、KPI、房贷、催婚、脱发……），可以换成更贴你的观众的词。
- `game.stages`：只留你想要的世界。比如深夜场只开 `["snow","slime","rain","beach"]`（声音最绵密、最助眠的几个）。

### 1.3 投放（DOU+ / 直播加热）

据第三方运营文章介绍，DOU+ 支持「自定义定向」，可以按性别、年龄、地域、兴趣来选人，还可以选「达人相似粉丝」。建议：

- **年龄**：不要选最小的年龄档，从 24 岁以上的档位开始试（具体有哪些档位、最小能选到多少，以你后台看到的为准）。
- **兴趣**：解压、ASMR、助眠、治愈、盲盒 / 潮玩、手作、宠物。
- **达人相似粉丝**：选几个成年观众为主的解压 / ASMR / 助眠 / 捏捏乐账号。
- **先小额、多组**：每组只改一个条件，播完看观众画像，留下年龄分布对的那一组再加预算。**不要**用"系统智能推荐"起步——它会沿着现有的（偏小的）人群继续找。
- 投放只是把第一批人换对；之后靠内容把他们留住，标签才会慢慢纠正过来。可能需要连续好几场。

### 1.4 用短视频选人

直播间的人很大一部分是从你的短视频来的。把直播里的高光剪成 10~20 秒的竖屏短视频：

- 观众写的「加班」「周一」被一脚踩扁（配文："评论区写下你的烦恼，今晚直播帮你踩"）；
- 多米诺一路倒到底；开出传说款盲盒的瞬间；脆脆桥"咔嚓"掉下去。

文案和评论区引导都对着成年人说。短视频吸引来什么人，直播间就会是什么人。

### 1.5 如果这一场就是小朋友多

不要引导送礼物（未成年人不能打赏，诱导未成年人消费是平台重点治理的行为）。把这一场当成练手，下一场换时段和定向。

## 2. 留人：开场 3 秒和"每 40 秒一个钩子"

运营文章的共识是：在评论、点赞、关注、加粉丝团这些互动指标里，**停留**最重要，而且这一场的数据会影响下一场拿到的流量。

**新观众刷进来的前 3 秒**，他要能看懂三件事：这是什么、现在在发生什么、我能做什么。画面上已经有（应援条、提示、投票面板），你开麦再说一遍效果会好很多：

- "新进来的朋友，弹幕打出你今天最烦的事，两个字就行，糯糯马上帮你踩扁。"
- "应援条还差一点点，点点赞，满了天上掉盲盒。"

**程序给你准备好的钩子**（大约每 40~60 秒一个），到点就喊：

| 画面上出现 | 你可以说 |
|---|---|
| 盲盒蛋掉下来 | "要开盲盒了！快点赞，赞越多越容易出稀有款！" |
| 三选一礼盒 | "1 号、2 号还是 3 号？有一个是整蛊的！弹幕打数字！" |
| 脆脆桥 | "左还是右？有一块是脆的！相信你的直觉！" |
| 终点宝箱 | "12 秒！点赞！发弹幕！还差一点点就砸开了！" |
| 应援条攒满 | "谢谢 XX 点亮了盲盒！"（画面上有名字） |
| 烦恼泡泡 | 把泡泡上的字念出来："XX 的『老板画饼』——踩扁！" |
| 一关结束 | "这一关的 MVP 是 XX！图鉴开到第 N 个了，还差 M 个集齐甜品系列。" |

**点名**是最便宜、最有效的留人手段。应援榜、MVP、烦恼泡泡上的昵称，都是给你念的。

**给明天留一个理由**："图鉴 35 个，今天开到 12 个，明天晚上 9 点继续。"盲盒图鉴的进度是跨场次保存的，就是为了这句话。

## 3. 把免费互动变成流量

来的人不送礼物不要紧——对一个新直播间，免费互动更重要，因为它们决定平台给不给你推更多的人。程序把每一种免费互动都做成了看得见的东西：

| 观众的动作 | 程序里的回报 | 你的引导 |
|---|---|---|
| 点赞 | 应援条上涨、爱心、盲盒稀有度、宝箱进度 | "点赞给糯糯加力气" |
| 评论 | 飘字、投票、烦恼泡泡、指令；上应援榜 | 提问式引导：选几号？今天最烦什么？下一关去哪？ |
| 关注 | 点名感谢、糯糯挥手、+30 应援 | "点个关注，明天继续开图鉴" |
| 加粉丝团 | 金色提示、点名感谢、+50 应援 | "加入粉丝团，糯糯专门谢你" |
| 分享 | 点名感谢、+20 应援 | "分享给今天也在加班的朋友" |

**福袋**（平台自带功能）很适合这个项目：参与方式选"发送口令评论"，开奖倒计时设成几分钟（具体能选哪些条件，以你后台看到的为准）。口令可以设成一句和内容有关的话，比如"加班退散"——观众每发一次口令，应援条就涨一点，第一个发的人还会得到一个带自己昵称的烦恼泡泡。倒计时期间观众会留下来。有文章提醒：福袋发得太频繁会吸引只为领奖的人，按自己的情况取舍。

## 4. 关于变现

现实一点：公开报道里说得很清楚，这类互动玩法里愿意付费的始终是少数重度用户，大多数人只做免费互动；而且高度依赖平台流量。所以顺序应该是 **先把人群换对、把停留和互动做上去，再谈钱**。

在这个前提下：

- **把送礼的门槛降到最低**。程序里 1 抖币的小礼物也会当场弹卡片、跳舞、上应援榜——口播里就说"一个小心心糯糯就给你跳舞"。成年观众的小额、冲动型礼物靠的是"我的名字出现了""它为我跳舞了"这种即时回报。
- **中礼物的"专属感"**：10 抖币以上会把名字踩进雪地 / 沙子里留一整关——可以主动介绍。
- 礼物以外的路（小黄车卖解压玩具 / 捏捏 / 史莱姆、品牌合作等）需要相应的资质和平台权限，也有各自的规则，这里不展开；如果观众是成年人、内容又是解压，这些方向和内容是对得上的。

## 5. 合规底线

- **录播 / 挂机**：2025 年 9 月抖音发布《关于治理录播挂机的公告》。据报道，平台当年已处理超过 45 万个涉及"录播""挂机"的直播间（警告、中断、封禁），情形包括播放录制内容、定格 / 黑屏、几乎没有互动、用插件做无真人直播等；平台强调直播要"所见即所得"——真实、实时、可互动。**本项目的画面是实时渲染的，观众互动会实时改变画面；但没有真人、长期无人看管的直播间是否会被判定为挂机，由平台决定，没有人能替你保证。** 建议：有人在场，开麦互动；不要 24 小时不间断地播；不要相信"无人直播稳赚"的教程。
- **未成年人**：未成年人不能打赏；平台对涉及未成年人的违规处理很重。不要用针对未成年人的话术。
- **不要承诺回报、不要虚假倒计时**。程序里的倒计时都是真的（到点真的揭晓）；盲盒是画面里的收集玩法，没有真实奖品——口播时不要说成"抽奖""中奖"。想发真奖品请用平台的福袋。
- **观众的字上屏**：有过滤，但没有百分之百；没人盯着的时候建议关掉（控制台里一个勾）。
- **数据来源**：读取自己直播间的公开弹幕属于非官方方式；官方途径是抖音开放平台的直播小玩法。

## 6. 每一场的检查清单

**开播前**
- [ ] 标题、封面、话题是写给成年人的
- [ ] 时段对（晚 9 点后优先）
- [ ] 直播伴侣是竖屏，糯糯窗口铺满画布
- [ ] 福袋、粉丝团入口准备好

**开播后 2 分钟内**
- [ ] 控制台「连接体检」绿灯
- [ ] 用手机发一条弹幕、点几个赞：计数在跳，画面有飘字和爱心
- [ ] 手机上看一眼自己的直播间：字看得清、糯糯没被挡住、声音正常

**直播中**
- [ ] 每个钩子都喊出来；念名字
- [ ] 留意右边监听小图：出现验证码就处理一下

**下播后**
- [ ] 看数据：平均停留时长、互动率（评论 / 点赞 / 关注 / 粉丝团）、**观众年龄分布**
- [ ] 年龄还是偏小 → 调时段和定向；停留短 → 看开场和钩子；互动少 → 多提问、多点名
- [ ] 剪 1~2 条高光短视频
